# Deco Blocks v7

These docs are being written. v7 is the current released version of the framework (the `@decocms/blocks`, `@decocms/blocks-admin`, `@decocms/blocks-cli`, `@decocms/tanstack` and `@decocms/nextjs` packages). Until its pages are here, the guides in the repository cover it:

- [The repository README](https://github.com/decocms/blocks#readme): the packages and how they fit together.
- [Fast deploy](https://github.com/decocms/blocks/blob/main/docs/fast-deploy.md): serve content from Cloudflare KV, so a content change doesn't need a redeploy.
- [Observability](https://github.com/decocms/blocks/blob/main/docs/observability.md): the metrics, traces and logs the framework emits.
- [Troubleshooting](https://github.com/decocms/blocks/blob/main/docs/troubleshooting.md): common errors and their fixes.
- [Migrating a site to TanStack Start](https://github.com/decocms/blocks/blob/main/.agents/skills/deco-to-tanstack-migration/SKILL.md): the playbook for moving a Fresh/Deno site to v7.
- [The docs folder](https://github.com/decocms/blocks/tree/main/docs): every other guide and runbook.

The [Next major](/next/architecture) docs describe the proposed API for the next major version.
