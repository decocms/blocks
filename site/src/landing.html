Headless for developers

Write a function, type its inputs, and it's a block. Deco Blocks stays out of your stack: no database and no content API to run, just JSON files in your repository and a small SDK that works with Next.js, TanStack Start, or any JavaScript server.

Editable for humans

Native for AI

Content is typed JSON in Git, so coding agents read, edit, and validate it with the tools they already have. Their edits arrive as ordinary commits your team reviews like anyone else's, and the same types that build the editor keep them honest.

Nothing extra to run

Your site ships with its content. If the hosted CMS fails, your site doesn't.

Your pages, banners and settings are files in your own repository, and every deploy carries them alongside the code. The content your visitors see is already inside your site, even when you publish through the optional hosted Deco CMS.

Hosted Deco CMS · optional

Publish in minutes, not on the next deploy.

The hosted Deco CMS adds Deco Studio, the visual editor, and publishing without a redeploy: each change reaches every visitor within about five minutes, and editors preview drafts on your real pages first. Without it, developers and agents edit the files, and content goes live with your next deploy.

Three steps, no ticket

Your function stays. Its inputs move into a file.

No rewrite and no new runtime. Name the function in a block map, generate a form from its types, and connect your app to your content with one call.

Deco Blocks · my-store — setup
{{icon:file}}cms.index.ts{{icon:terminal}}Terminal{{icon:file}}src/cms/cms.ts
// config/experiments.ts: the function you already have
export default function experiments(input: Experiments) {
  return { newCheckout: roll(input.newCheckout), /* … */ };
}

// cms.index.ts: give it a name in a block map
import type { Blocks } from "@decocms/blocks";
import experiments from "./config/experiments";

export default { experiments } satisfies Blocks;

{{icon:check}}The key experiments is now a block type content can refer to.

import { createCMS } from "@decocms/blocks";
import blocks from "../../cms.index";

// Production (with a token) reads the hosted Deco CMS;
// development reads the files in .deco.
export const cms = createCMS({
  loader: { token: process.env.DECO_SITE_TOKEN },
  blocks,
});

{{icon:check}}With the hosted Deco CMS (the token above), a commit is live everywhere within about five minutes, no deploy. Without it, content ships with each deploy.

Yours to keep

Small on purpose. Nothing hidden.

Deco Blocks is a small library and a folder of files in your own repository, not a platform you move into. You can read how the library works, swap any piece of it, and keep all of your content whatever you decide next.
