# Migration Known Issues — histórico acumulado

Checklist cumulativo de problemas já enfrentados em migrações Fresh/Deno → TanStack Start
(e na migração de pacote `@decocms/start` → split 7.x). Use como validação ao migrar cada
nova loja: percorra as categorias e confirme que cada sintoma **não** ocorre na loja migrada.

Toda linha tem uma coluna **Fix no framework** que estampa um destes três estados,
verificado contra o histórico real do repo (`git log`/testes de regressão), não só contra
a descrição do problema:

- **✅ Corrigido** — existe PR/commit/teste de regressão no `decocms/blocks` que resolve isso; a coluna cita a referência.
- **🟡 Parcial** — parte do problema tem fix no framework, mas um caso residual ainda exige atenção/workaround no site.
- **❌ Sem fix no framework** — não há e não pode haver mudança de código neste repo que resolva isso (limitação de plataforma, comportamento por design, bug em outro repo, ou erro de autoria no código do site). A coluna explica o motivo.

Ao encontrar um problema novo numa migração futura, adicione-o aqui (não em memória solta,
não só num PR) — este arquivo é a fonte única de verdade para "já vimos isso antes". Se
tiver dúvida do status, rode `git log --all --oneline -i --grep="<palavra-chave>"` antes de
estampar "sem fix" — várias entradas aqui já foram corrigidas depois de reportadas.
